EXPORTING PHYSICSPUZZLE TO .EXE
=================================

This folder is ready to receive your exported game!

STEP-BY-STEP EXPORT GUIDE:
--------------------------

1. INSTALL EXPORT TEMPLATES (First Time Only)
   - Open Godot 4.5
   - Click: Editor menu → Manage Export Templates...
   - Click: Download and Install
   - Wait for download (~450 MB)
   - Click: Close

2. CREATE EXPORT PRESET
   - Click: Project menu → Export...
   - Click: Add... button
   - Select: Windows Desktop
   - Preset appears on left

3. CONFIGURE SETTINGS
   In the Export window:
   - Application tab → Check "Runnable"
   - Binary Format → Check "64 Bits"
   - Binary Format → Check "Embed PCK"
   - Leave other settings default

4. EXPORT THE GAME
   - Click: Export Project button (bottom right)
   - Navigate to this "builds" folder
   - Filename: PhysicsPuzzle.exe
   - Click: Save
   - Wait 5-30 seconds

5. TEST YOUR GAME
   - Double-click PhysicsPuzzle.exe in this folder
   - Play through levels to verify
   - Share the .exe file with anyone!

EXPECTED OUTPUT:
----------------
PhysicsPuzzle.exe (~60-90 MB)
- Single file contains entire game
- Runs on Windows 10/11 (64-bit)
- No installation needed

TROUBLESHOOTING:
----------------
- "Templates not found" → Go back to step 1
- Windows Defender warning → Click "More info" → "Run anyway"
- Won't launch → Right-click → "Run as administrator"

Your game is ready to be exported!
