# PhysicsPuzzle v1.0 🎮

A challenging physics-based puzzle game with strategic gameplay!

## 🎯 Features

- **5 Progressive Levels** - From basic training to master challenge
- **4 Object Types** - Regular box, heavy box, circle, and bouncy ball with unique physics
- **Resource Management** - Limited objects per level forces strategic planning
- **Dynamic Obstacles** - Navigate platforms, avoid hazard zones, work around walls
- **Strategic Gameplay** - Think ahead to find the optimal solution
- **Win/Loss Conditions** - Complete objectives or face defeat

## 🎮 How to Play

1. Download `PhysicsPuzzle.exe` below
2. Double-click to run (no installation needed)
3. Use keys **1-4** to select object types:
   - **1** - Regular Box (balanced physics)
   - **2** - Heavy Box (stable, high friction)
   - **3** - Circle (rolls easily, navigates tight spaces)
   - **4** - Bouncy Ball (high rebound, chaotic)
4. **Click** anywhere to place the selected object
5. Get the required number of objects into the green target zone
6. Press **R** to reset the current level

## ⚙️ System Requirements

- **OS:** Windows 10/11 (64-bit)
- **Storage:** ~90 MB disk space
- **Dependencies:** None (standalone executable)

## 📝 Level Overview

- **Level 1:** Basic Training - Learn the fundamentals (3 objects, 8 available)
- **Level 2:** Elevated Target - Stack objects to reach platform (3 objects, 7 available)
- **Level 3:** Danger Zone - Avoid red hazard areas (4 objects, 8 available)
- **Level 4:** Bridge Builder - Cross the gap between platforms (5 objects, 10 available)
- **Level 5:** Master Challenge - Combine all skills (6 objects, 12 available)

## 🎯 Gameplay Tips

- Heavy boxes make excellent foundations but are harder to move
- Circles can roll into tight spaces that boxes can't reach
- Bouncy balls can reach elevated targets but are unpredictable
- Plan your moves - you have limited objects!
- Each level has hidden "par" goals for efficient play

## 🐛 Known Issues

- First launch may trigger Windows Defender warning (unsigned executable)
  - Solution: Click "More info" → "Run anyway"
- Some antivirus software may flag the .exe
  - Solution: Add exception or temporarily disable antivirus

## 🔧 Troubleshooting

**Game won't launch:**
- Ensure you have Windows 10/11 64-bit
- Try running as Administrator (right-click → "Run as administrator")
- Check that antivirus isn't blocking the file

**Performance issues:**
- Close other applications
- Update graphics drivers
- Game should run smoothly on most modern PCs
